# Diccionario de datos

| Variable | Descripción |
|---|---|
| `id` | Identificador único de la observación |
| `nombre` | Nombre de la persona encuestada |
| `ciudad` | Ciudad de residencia |
| `fecha_encuesta` | Fecha en la que se realizó la encuesta |
| `ingreso_mensual` | Ingreso mensual reportado, en pesos |
| `nota_promedio` | Promedio académico en escala de 0 a 5 |
| `trabaja` | Indica si la persona trabaja |
| `comentario` | Observación registrada durante la encuesta |

## Nota

El archivo original contiene inconsistencias intencionales. El diccionario describe el significado de las variables, no el formato en que fueron almacenadas.
